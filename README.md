# Lekan Adeyeri

Personal academic and research homepage for Lekan Adeyeri.

The site is a lightweight Jekyll/GitHub Pages site with publications stored as Markdown files in `_publications`, BibTeX entries in `data/bibtex`, and publication images in `data/images`.

## Local development

```sh
bundle install
bundle exec jekyll serve
```

## Publications

Only publications with `owner: lekan` render on the homepage. Inherited publication records and unused inherited assets are archived under `_archive/group-publications` so they remain reversible without being published in the generated site.
